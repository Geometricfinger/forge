# Five independently labeled handoff fixtures

These files were created by the independent contract reviewer before executing
the new handoff implementation. The original planner specification and code were
read to preserve their existing behavior. No handoff implementation supplied
these labels, and no optimizer was used to generate the expectations.

H01 and H02 use synthetic CSV headers from Medit's documented case-list items.
Those docs do not establish exact installed-export encoding, dialect, localized
headers or a versioned wire format. The extra Implant Identity column in H02 is
deliberately unsupported and must not affect the supplied histories.

H03 is an explicitly synthetic reviewer-created native-route manifest with raw
byte pointers and an exact quoted observation of a documented content category.
Its opaque payload says it is not a vendor 3OXZ file. Passing H03 demonstrates
the reviewed manifest boundary, not proprietary native decoding or authenticity.
H04 references actual synthetic STL text and cannot be promoted to a native
case even by a quoted claim. H05 retains contradictory matching-case rows.

Every decision, history, answer and question is supplied. Conditions are fixed
reviewer declarations. Missing values retain those histories; they never create
new ones. The same original model is retained as a manual counterfactual for
each case. All follow_up lists are empty, so suggested questions cannot reduce
the observed unresolved count. Evaluation truth lives only in expected.json.

The three unknown human events are declared required tasks, each with step_count
one, not observations that a human performed work. Their elapsed times are null.
Runtime adapter events can be timed, but complete human burden and savings remain
unmeasured. A separate synthetic-duration test verifies arithmetic without
relabelling its values as observed human time.

The freeze pins every fixture, raw artifact, expectation and this explanation.
It is trusted-workspace consistency evidence, not authenticated chronology.
Never regenerate its timestamps during routine verification. The test-first
constructor is retained separately by the parent experiment record.
