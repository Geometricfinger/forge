# Workbench 0.6 acceptance, recorded before implementation

Scope: research-informed retrieval and context over approved Python metadata. Preserve original Hound and all 280 Workbench tests. No collected code execution, source writes, permission changes, or paid/model calls.

Required behavior:
1. Search names, documentation, parameters and declared call syntax separately. Imported aliases may provide DECLARED, never executed, API leads. Nested-body calls must not leak into an enclosing function.
2. Weighted BM25 ranking and rank fusion use documented equations. Rank is not confidence. Exact symbols and full query coverage retain explicit preference. Rare discriminative terms and field evidence must be inspectable.
3. Exact text copies must not cast extra ranking votes. A grouped result retains every original occurrence and does not claim interchangeability, identical rights or dependency closure. Default programmatic occurrence enumeration remains compatible.
4. Required API filters use Hound observations, not documentation or an unverified import. Unestablished requirements remain unestablished. Natural language negation is flagged, not claimed as understood.
5. Source-bound context returns local/import helper leads in the same container and archive namespace; ambiguity, shadowing, missing imports, unresolved attributes, cross-cell semantics and dynamic dispatch remain visible. Do not concatenate transcripts or infer arbitrary external targets.
6. Legacy report metadata remains readable, with missing structural context labeled. Query/index changes invalidate cached index versions; no source execution is needed to search.
7. Compare against the exact previous release on unchanged source snapshots, plus frozen source-reviewed retrieval tasks. Report changes including regressions. Development data is not independent benchmark evidence.
8. Search, context, filters, and grouped results work through the actual CLI/HTTP routes. Preserve source hashes and original tests. Inject faults in grouping/context/constraints and require detection.
9. The final ZIP must be unpacked, verified and retested. Native/hosted limits must remain honest.
