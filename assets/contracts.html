work across tools.

A Python producer and a JavaScript consumer can write the same record differently. This opt-in adapter gives admitted JSON records a shared canonical representation. It never replaces existing FORGE identifiers.

Fingerprint a record

Duplicate keys, invalid Unicode, unsafe integer values and nonzero numeric underflow are rejected. Exact-decimal identifiers and large IDs belong in strings. This is not a signature or schema validator.
