# Product direction and implementation status

<sub>First written at internal milestone 0.4; the current release version is in [VERSIONS.md](VERSIONS.md). See [ARCHITECTURE.md](ARCHITECTURE.md) for which component owns what.</sub>

The objective is a private, evidence-backed capability-reuse workbench. This release implements the missing requirement comparison and packet step, plus one supervised first-party execution path. It does not claim the full competitive roadmap has been delivered.

## Implemented and exercised

Frozen requirement cases and exact source locks; real symbol grouping and separate source scope; three evidence categories; append-only review revisions with current-head checks; source staleness; portable packet hashing; CLI/HTTP/UI integration; fixed first-party JSON experiment; retained Hound and prior improvement workflow.

## Nonnegotiable

Never promote a similar name or API observation into verified behavior. Do not reset or relabel failed tests. Do not treat a repository's license label as intended-use permission. No arbitrary execution through data-only requirements, notes or discovery output. Never erase evidence to make a candidate appear eligible.

## Still open

1. Independent external requirement-to-integration benchmark and observed user trials.
2. Native Mac/Windows and real browser-to-server/network qualification.
3. Explicit versioned workspace migration and coherent flattening of legacy engine bundles.
4. Reviewed external evaluator interface, dependency capture, isolated execution and protected acceptance.
5. Broader semantic/dependency retrieval and provider coverage.
6. Team authentication, supported persistent hosting, policy administration and business validation.

Contributions are not permission to change billing, expose private source, execute unknown code, or modify unrelated applications. This local increment has no cloud deployment or running agent service.
